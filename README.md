# Nature Metaverse — Cinematic 3D Planet Explorer

An ultra-premium, cinematic, photoreal-inspired 3D nature exploration experience featuring:

- Google Earth-style exploration flow (orbit → continent → landscape → macro flower)
- Unreal-style real-time scene dynamics (fog, lighting shifts, particles, animated ecology)
- Apple-level premium glassmorphism UI and smooth transitions
- Metaverse-inspired shared-world section with teleport interactions and avatar presence
- AR/VR capability checks via WebXR-ready controls

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.
